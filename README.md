# Crack Any Egg

**EARLY EXPERIMENTAL PRE-RELEASE!!**

This mod is under development, and will be updated to a 1.0.0 release once adequate testing is completed.

This is a lightweight, data-only mod for the Vintage Story game to add [A Culinary Artillery](https://mods.vintagestory.at/aculinaryartillery) (ACA) egg-cracking compatibility to eggs from other mods that do not already have compatibility patches bundled with ACA.

This mod is inspired by, and marginally fancier than, [Feverstone Eggs Lazy Compatibility](https://mods.vintagestory.at/feverstoneeggslazycompat).

This mod uses ACA's built-in ```EggCrack``` behavior to Ostrich and Cockatrice eggs, which has built-in support to give back different volumes of liquid. 

Cockatrice eggs give 0.4L (=4 chicken eggs) and Ostrich eggs give 0.8L. Both give liquid chicken egg when cracked, which both avoids introducing any new item IDs, and improves game immersion by reflecting the factual real-world reality that every bird is actually a Chicken Of Unusual Size. 

For now, the mod **does not support separating egg white vs yolk**, because of built in limitations in the ACA EggCrack that would result in getting differing amounts of each. Instead, shift-clicking will give whole egg liquid.
